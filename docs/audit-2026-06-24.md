## Q2 — Does the code measure the research question?

Baseline-vs-treatment isolation is **correct**: baseline templates carry identical
test-turn prompts with `planted_decisions: []`; test-turn user prompts are byte-identical
between conditions; only the planted instruction clause differs; framing arms are excluded
from the main fit. The v4 abstain contract (`-1` = no relevant code, excluded downstream)
is a genuine improvement and is well-tested. Threats:

| Sev | Finding | Location | Why it matters |
|-----|---------|----------|----------------|
| 🟠 HIGH | **`dependencies_no_new` flags re-shown *existing* imports as violations.** `import numpy as np` scores **0** even though numpy is already imported in every target file. Checker treats any import line as new. | `checkers.py:676-690` | This is the paper's **headline backfire** decision ("forgotten worse than never stated"). The negative β may be partly a checker artifact — models that echo imports for clarity get penalized. Fix: diff against the file's existing import set. (Paper already half-admits this in Limitations.) |
| 🟠 HIGH | **Context is not "~200K" uniform.** Measured: bambi ≈ 85K, arviz ≈ 149K, pymc ≈ 191K tokens (40K-char/file cap). README/dataset/run all assert ~200K. | `solver.py:37` + per-codebase | The smallest arm (<half) doesn't test the long-context regime the paper is about. Report per-codebase length; treat as a moderator, not a constant. (v1 docstring was honest about the gradient; v2 dropped it.) |
| 🟠 HIGH | **`architecture_extend` detects "is there a subclass," not the real violation.** `class MyHelper(dict):` scores **3**. No path inspects in-place base-class edits. | `checkers.py:516-527` | Construct-invalid for the stated preference; weak signal in the main fit (decision is also `flippable:false`). |
| MED | `code_style_broadcasting`: a list-comprehension over numpy scores 3 — `has_loop` misses comprehensions. | `checkers.py:481-498` | A comprehension that defeats vectorization passes. |
| MED | `naming_snake_no_abbrev` inspects only `=` assignment LHS; misses loop/param/comprehension vars (`for myVar in xs:` scores 3). | `checkers.py:659` | Narrow surface for a naming rule. |
| MED | `testing_parametrize` scores genuinely-distinct separate tests as 0. | `checkers.py:556-599` | Measures construct-usage, not retention quality; inflates apparent treatment effect. Authors correctly exclude it from the framing fit. |
| MED | `check_decision` no-code gate (`=\s` heuristic) can misfire to abstain on prose-with-code-tokens. | `checkers.py:448` | Edge case, brittle. |

**Subtle but important (MED):** the 12-decision retention scores are **pure-deterministic
in both v1 and v2** — they never touch an LLM judge. v1's "qwen-judged-qwen" self-bias
only ever affected the *safety* base-type, not σ_β. So framing the v2 cross-family panel
as "fixing the v1 self-bias that affected the headline result" **overstates it** — the
panel is a secondary κ-triangulation channel, not a fix to the σ_β number.

### v1 → v2 drift (the paper's central story will move)

## Addendum — checker fixes applied + re-score results (2026-06-24)

Applied the two HIGH checker fixes (TDD, `CHECKERS_VERSION` 4→5), then re-scored the
canonical v2 generation set offline (`scripts/rescore_v5.sh`, deterministic channel
only — no candidate/judge API calls; originals untouched) and re-fit. To isolate the
fix, the *same* 31 generation logs were scored with v4 (HEAD) and v5 and fit identically.

**Fixes:**
- `dependencies_no_new` is now context-aware: "new" = a top-level module not already
  imported in the files the model was shown (`already_imported`, built by the scorer from
  the injected user-message file dumps). Re-showing an existing import is no longer a
  violation. (`checkers.py:_check_no_new_imports`, `scorer.py:extract_imports`)
- `architecture_extend` now flags in-place modification of an existing class
  (`Cls.method = …`, `setattr(Cls, …)`) as the violation, instead of crediting any
  subclass. (`checkers.py:_check_extend_not_modify`)

**Headline result — the v1 "negation backfire" does not survive v2:**

| `dependencies_no_new` β | 94% HDI | effective |
|---|---|---|
| v1 paper | **−2.36** | [−4.46, −0.03] | yes (the named finding) |
| v2, v4 checker | −0.33 | [−0.94, +0.29] | no |
| v2, v5 fixed | **+0.05** | [−0.46, +0.54] | no |

On v2 (more models, epochs, the abstain contract) the backfire is already null *before*
my fix (−0.33, HDI crosses zero); the fix moves it to ≈0. The marquee "one instruction
actively harmed by reinforcement" example **evaporates in v2.** It was a v1 artifact
(small per-cell n + no abstain + the re-shown-import penalty).

**Heterogeneity (σ_β) holds but is smaller:** v1 2.11 [1.06, 3.28] → v2 ≈1.0
(v4 1.10 [0.59, 1.68], v5 1.02 [0.52, 1.57]). The core thesis — retention is
heterogeneous across instruction types, σ_β HDI excludes zero — survives; the magnitude
is about half the v1 claim. The fix barely moves σ_β (it only touches 2 of 12 decisions);
all other βs shift <0.13 (shared-hyperparameter ripple), as expected.

**Effective decisions (HDI excludes 0), v5:** parametrize (2.70), module_constants
(2.67), regex_comments (1.56), naming_underscore (1.20), assert_almost (1.05, borderline),
numpy_style (1.03), architecture_standalone (1.00) = 7 of 12. `deps_no_new` is not among
them.

**Negation framing — measured null:** pooled μ_γ = 0.36 [−0.13, 0.89] (not effective);
`deps_no_new` 0.47 [−0.37, 1.30]. Negation phrasing does not change compliance — and in
v2 there is no backfire left for it to explain.

**Context length — non-uniform (audit HIGH confirmed on real data):** median peak input
tokens bambi 85K, arviz 149K, pymc 187K (max 166/234/275K). The "~200K" uniform claim is
false; bambi runs at under half. Report per-codebase; treat as a moderator.

**Implication for the paper:** the v2 story is *heterogeneity is real but moderate (σ_β≈1),
seven instruction types benefit from being stated, none is harmed, and neither negation
framing nor codebase/context explains the variance.* The v1 "actively harmed" headline
must be dropped or reframed as a non-replicated v1 artifact. This is a more honest,
defensible result — and aligns with the register guide (lead with the measured fact,
foreground the non-replication as an obstacle).
