## C0 — CURRENT IN-PAPER (prior 5/0 blind winner)
Autonomous coding agents follow instructions given once at the start of a run, with no one to restate them as context accumulates. Adherence erodes, and a mean compliance rate shows how many instructions survive but not which one. For a safety constraint, only the second question matters. We measure retention one instruction at a time. Across 25-turn coding sessions on three open-source Python codebases and five models, we plant twelve ordinary coding preferences as casual inline requests, score each model's later code with deterministic checkers on a 0–3 ordinal scale, and fit a Bayesian ordered-logistic model with hierarchical effects per decision type. The estimated effects span −2.4 to +5.4 on the log-odds scale (group-level standard deviation 2.1): most preferences are already followed by default, and only three of twelve benefit from being restated (two under a single-model robustness check). A planted preference stands in for a safety guardrail, since both are instructions competing for attention, so the heterogeneity carries a safety reading: aggregate compliance can stay high while the one rule that matters has been dropped. The baseline comes from a single model, which limits any claim of model-invariance, and compliance is a snapshot at turns 20–25 that does not trace how retention decays.

### A1

Twelve coding preferences were planted as casual requests inside 25-turn coding sessions across three open-source Python codebases; deterministic checkers scored each preference on a 0–3 ordinal scale at turns 20–25, and a Bayesian ordered-logistic model with hierarchical effects per decision type estimated the treatment effects.
